# Yuvraj Riyar — Portfolio

**Live site:** [yuvrajriyar.vercel.app](https://yuvrajriyar.vercel.app)

A personal portfolio for my work across data, business, financial, operational, and sports analytics. It brings together project case studies, experience, technical capabilities, my résumé, references, and the parts of life that keep me curious outside work.

## Featured work

- **EstateFlow:** an end-to-end housing-market pipeline with an editable Power BI report covering a national overview, a state and metro explorer, and a reader's guide.
- **ProTech:** an athlete-performance platform built with Aggie Sports Analytics for UC Davis Football, including team and case-competition imagery.
- **Dispatch Command Centre:** an internal Python application supporting load visibility and daily fleet planning at Soaring Roadlines Inc.
- **NBA Injury Risk Analysis** and **King County Housing Market Analysis:** statistical modelling case studies.

Every project has a dedicated page with context, methods, visuals, and links to the available implementation.

## About the site

The design pairs a dark, restrained visual identity with a more personal voice: practical analytical work alongside sport, travel, Neapolitan pizza, espresso, and the people and experiences that matter to me.
